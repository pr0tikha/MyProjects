# **App Name**: PayMind

## Core Features:

- Individual Reminder Setup: Allow users to set one-off or recurring reminders for various payments or activities.
- Recurring Payment Scheduling: Enable users to log their monthly recurring expenses (rent, policy payments, etc.) with specific dates and times.
- Dynamic Reminder Timing Tool: Automatically set the default reminder time based on the user's typical wake-up schedule derived from mobile data and apply a bit of reasoning to decide whether this timing is useful.
- Expense Log Management: Enable users to add, delete, and modify expense entries within the log.
- Notification System: Generate reminders at the specified date and time with a bell sound notification.
- Notification Actions: Allow users to 'snooze' or 'mark as paid' directly from the notification.

## Style Guidelines:

- Primary color: #7984D7 (a moderate blue-purple) evokes trust and responsibility.
- Background color: #F0F2F9 (a very pale tint of the primary) for a clean and uncluttered look.
- Accent color: #A577B2 (a vibrant violet) will attract attention for important actions such as setting reminders and confirming payments.
- Body and headline font: 'PT Sans', a modern and clear font suitable for displaying dates, amounts, and reminder descriptions.
- Use simple and recognizable icons for expense categories and reminder actions.
- Prioritize a clean, intuitive layout, optimizing for the smaller screens on mobile devices
- Use gentle transitions and animations when navigating through the expense log and setting reminders.
